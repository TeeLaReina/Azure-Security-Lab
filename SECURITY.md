# Security Policy

## Reporting

This is a portfolio/learning repository. No production systems are represented.
All Azure resource names, subscription IDs, and tenant IDs visible in screenshots 
have been blurred before upload.

## What to Do If You Spot Sensitive Data

Open an issue immediately. Sensitive data will be removed from history within 24 hours.

## Secrets Policy

No secrets, keys, connection strings, or credentials are ever committed to this 
repository. All authentication uses Managed Identities or environment variables.
